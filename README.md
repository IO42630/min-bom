# min-bom

* A bom-pom for `min` projects.
* `min-bom` vs `min-root`:
    * while `min-root` determines plugin versions & CI/CD,
    * `min-bom` determines dependency versions. 

## CI/CD

- detailed instructions can be found in `services/hosts/mvn-central`
- `brew install gnupg`
- verify `.env` is correct
